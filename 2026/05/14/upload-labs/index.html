文件上传靶场

发表于2026-05-14|更新于2026-05-27|渗透知识点
|总字数:1.8k|阅读时长:9分钟|浏览量:

pass-01

本关只进行了javascript的过滤，可以在浏览器中关闭javascript选项，即可上传成功。

上传webshell.php文件即可

pass-02

本关只对文件类型做了过滤，因此使用burpsuit工具来更改数据包即可通过

pass-03

本关对上传的文件后缀有过滤，但是这个过滤并不完整，可以将文件的后缀改成php5等数字来绕过

pass-04

.htaccess文件解析漏洞：Apache 服务器的配置文件上传与解析绕过漏洞，核心是攻击者上传恶意 .htaccess 篡改目录解析规则，将普通文件（如图片）当作 PHP 执行，最终 getshell

先将webshell.php文件改成.jpg文件，上传进去，然后再将.htaccess文件上传

pass-05

这关将.htaccess文件给过滤了，但是放出了个.ini文件，因此利用这个漏洞来创建.user.ini文件

.user.ini 解析漏洞：在执行当前目录下所有 PHP 文件之前，自动包含并执行指定的文件。

条件：

  1. 服务器是 PHP + Nginx/Apache
  2. PHP >= 5.3.0（支持 .user.ini）
  3. 上传目录允许 PHP 解析（有 php 文件）
  4. 上传未拦截 .user.ini
  5. 服务器未禁用 .user.ini 读取

pass-06

看完源码发现，本关并未将文件名的后缀转成小写，而过滤名单中，只存在小写的后缀，因此只需要将后缀改成大写，即可绕过。

pass-07

本关的源代码中有严重漏洞，他只检查最后一个点后面的后缀名，如果构造后缀名时使用webshell.php.jpg则只会认为后缀时jpg，过滤名单直接无效
